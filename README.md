# WELLSCAPE 
WELLSPACE is a personalized wellness tracking application that combines daily wellness monitoring with a Filipino-themed top-down multiplayer game. Users can record their sleep duration, food and water intake, and mood. The application analyzes their inputs using predefined formulas to provide wellness insights and practical recommendations.

To encourage consistent wellness tracking, users can explore a virtual world, interact with non-player characters (NPCs), socialize with other players through chat bubbles, customize their characters, and earn in-game rewards for maintaining their wellness routines.

The project aims to make wellness tracking more engaging, accessible, and socially interactive.
